## habitica-tools.github.io

This repository is automatically hosted at [habitica-tools.github.io](https://habitica-tools.github.io) and provides tools that help users of [Habitica](https://habitica.com/).

Currently the following tools are available:

- **Party Progress Info** for tracking and visualizing Habitica party progress ([wiki entry](https://habitica.fandom.com/wiki/Party_Progress_Info))


### How do I use it?

Visit the hosted website at [habitica-tools.github.io](https://habitica-tools.github.io) to access the "Habitica Party Progress Info" tool.

### What do I need?

All you need is a modern web browser.
